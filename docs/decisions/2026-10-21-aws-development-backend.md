# AWS development backend and database

Date: 21 October 2026. Scope: backend infrastructure only; Cursor owns ongoing feature work.

The owner approved AWS development provisioning with **US$10 monthly usage alerts** to the supplied NSUT address, replacing the proposed US$25 alert. The recipient is kept in ignored local configuration. Saved alerts at 50/80/100% actual and 100% forecast, their recipient, and credit exclusion were verified through AWS Budgets. They monitor usage, not enforce a cap; email delivery has not been independently observed.

The intended account was authenticated with AWS CLI browser login. The Free Tier API verified the Free Plan, US$100 remaining, and expiry on 21 April 2027. No paid-plan upgrade, long-lived key, production release, domain change or public signup was made.

Decision: Vercel remains the website target; use Mumbai AWS Lambda/HTTP API for the separate TypeScript core and Python discovery services. Use Aurora PostgreSQL Express 17.9 with IAM-only managed gateway access, verified TLS, min 0 / max 1 ACU, 300-second idle pause, one-day automated backups and deletion protection. Keep Python out of the private database. Use separate `goa_core` and `goa_migrator` SQL roles; the runtime role cannot create schema objects or modify migration history. Database statements use the existing PostgreSQL adapter with fresh IAM tokens and explicitly closed connections.

Actual API restrictions shaped the implementation: Express creation rejects an initial database name, so bootstrap creates `goa` after cluster availability; the Free Plan rejects seven-day backup retention, so this development database uses one day. The administrator can create roles but cannot set another role's default object privileges without membership, so grants are configured through the migration role itself. These restrictions were resolved without plan upgrades or TLS exceptions.

CloudFormation owns the budget, Cognito, assets, IAM boundary, and runtime resources. A retained custom resource bundles the current RDS SDK to create Express because `AWS::RDS::DBCluster` does not expose `WithExpressConfiguration`. The custom provider never deletes the database. Root browser credentials cannot directly assume IAM roles; runtime resource changes therefore execute through the scoped CloudFormation service role `goa-dev-deployer`. Application Lambda roles have a permissions boundary, explicit database user scope, and seven-day logs. The temporary caller session initiates CloudFormation and uploads packages. No administrator managed policy is attached to these roles.

Alternatives: private RDS micro is about US$17.95/month before secure egress/shared services in the retained same-day Mumbai comparison; supporting Cognito/JWKS egress from VPC Lambda adds networking work/cost. Aurora Express permits reuse of normal PostgreSQL transactions without NAT or a Data API rewrite. Render is operationally simpler but adds separately billed service/database hosting and still needs the existing Cognito integration. AWS matches the existing architecture and usable account credits.

Costs: at the verified regional US$0.18/ACU-hour, 60 active hours averaging 0.5–1 ACU costs US$5.40–10.80 for compute; storage, I/O, transfer, logs and other services remain separate. The illustrative US$11–16/month light-development scenario can exceed the chosen US$10 alert. Continuous 1 ACU activity alone is US$131.40 per 730-hour month. Free Plan credit depletion can end service before the plan expiry, and its Aurora storage limit is 1 GiB. Keep AWS usage and backups under review; do not promise free months or zero idle cost.

Rollback: restore the prior verified runtime artifact keys and apply `goa-dev-runtime`. Schema changes require a reviewed forward migration or a restored database; ZIP rollback does not undo SQL. The cluster is retained and deletion-protected. Export and restore-test data before explicitly authorized cleanup; retained snapshots, assets and logs can continue to consume storage. Failed provider log groups may remain with seven-day retention. A live backup restore and Vercel/browser journey remain launch gates.
