# Slice 04 — search a place, focus it and plan it

21 October 2026. Owner requests search inside the map, selectable results (for example Palom/Palolem Beach), dynamic focus and direct itinerary addition. Existing map/list actions, trip data and ledger remain intact.

The Python discovery service adds GET `/v1/search?q=&category=&region=`. It merges clearly labelled reviewed matches with bounded Goa OpenStreetMap results from a Photon-compatible configured endpoint. The modest local default is Photon's public demo, whose official documentation permits reasonable project use; production must explicitly configure its endpoint. No public Nominatim geocoding endpoint is used. Enforce bounded queries, Goa coordinates/state, time/response limits, cached repeated requests, serialized/throttled upstream work, no account/cookie forwarding and honest provider-unavailable metadata. No ratings, hours, bookings or activity inventory are invented. Existing `/places` contract stays compatible. Palom is a search alias for the already-reviewed Palolem; it is not a new place.

The web public BFF allows only the new search route and existing filters. Reusable search UI supplies debounced selectable results, loading/error/no-result states and keyboard selection. Selecting a result highlights/focuses its pin without creating a new Leaflet instance. Search/marker controls offer Add to itinerary, Save for later and source/map links. The public flow chooses an accepted trip; the private planner uses its current trip/day. Both use the existing versioned ActivityForm/API, explicit day/time/details and retry keys. Preserve coordinates, place ID and source context. No itinerary is changed by merely searching or selecting.

Acceptance: Palom search returns Palolem, broader Goa results are source-labelled, list selection focuses the same pin, and an explicit add saves the chosen trip/day with coordinates and notes, visible after reopening. Respect outsider/removal boundaries. Unit/service/BFF tests, build and live HTTP journey must be recorded; prior browser-policy denial remains binding, so rendered focus/mobile/keyboard is Not tested without permitted access. No cloud resources or paid subscriptions.
